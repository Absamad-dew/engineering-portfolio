## PTC Simbol

Кодек изображений для RGB и YUV. Сравнивал полный размер закодированного изображения и качество декода при заданном размере.

- **YUV 4:2:0.** Восемь кадров 1920 × 1080 из разных последовательностей [Xiph](https://media.xiph.org/video/derf/), целевой бюджет 0,2 бита на пиксель. PTC Simbol Ultra занял **392 188 байт** суммарно, AVIF speed 4 — **392 789 байт**. Совокупный PSNR PTC Simbol был на **0,062 дБ ниже**.
- **RGB.** На 20 изображениях с тремя бюджетами и полными вызовами кодера Ultra получил **+0,157 дБ** по совокупному PSNR и **−2,897 балла** по среднему SSIMULACRA2 относительно AVIF 4:4:4. В **10 из 60** сравнений результат выше по обеим метрикам. На одном кадре при бюджете около 0,6 бита на пиксель выигрыш составил **+0,357 дБ** и **+0,773 балла** при 153 820 байтах против 153 825 байт у AVIF.

## PTC RAM

Прототип сжатия памяти фоновой вкладки Chrome с последующим восстановлением. Экономия учитывает память вспомогательного процесса.

| Измерение | Результат |
| --- | --- |
| Прогон с побайтной проверкой на 1 536 МиБ данных вкладки | Выделенная память **3 431,6 → 2 051,4 МиБ**. Освобождено **1 380,2 МиБ**, восстановленные данные сверены побайтно. |
| Один снимок на 384 МиБ, одинаковые входные байты | **42,38 МиБ** у PTC RAM и **52,64 МиБ** у Zstd 3. Пакет меньше на **19,5%**. |
| Отдельное обычное пробуждение около 1,5 ГиБ | Первый ответ JavaScript через **213,4 мс** с момента запроса на пробуждение. В прогоне с побайтной проверкой из первой строки этот интервал составил **424,2 мс**. |

## PTC Chat

Точный архив диалогов с выборочным чтением отдельного разговора. В наборе девять диалогов с сообщениями, кодом и выводами инструментов.

| На одинаковых данных | PTC Chat | Brotli 11, отдельный кадр на диалог |
| --- | ---: | ---: |
| Полный архив | **1 920 442 Б** | 2 106 715 Б |
| Медиана первого запроса | 18,41 мс | 16,48 мс |

Архив PTC Chat меньше на **8,84%**. Все девять диалогов восстановились побайтно. Первый запрос измерен в свежих процессах с обычным файловым кэшем ОС. Размер установленного читателя учитывается отдельно от архива.

## PTC Mesh

Эксперименты по сокращению GPU-памяти геометрии и текстур. Замеры проведены на RTX 4060 Laptop GPU.

- **Геометрия.** В Direct3D 11 на сцене из восьми моделей Khronos и 249 933 треугольников расход локальной VRAM под геометрию снизился с **9,703 до 4,828 МиБ** (−50,24%). Исходные индексы и атрибуты восстановились побитно. Три контрольных кадра совпали. В той же серии p95 GPU вырос с **0,0932 до 0,0983 мс**.
- **Текстуры.** В отдельном стенде на 167 текстурах DOGWALK расход VRAM на текстуры снизился с **658,42 до 555,13 МиБ** (−15,7%). При чтении с GPU все 1 701 mip-уровень совпали с исходниками. В отдельной проверке внутри DOGWALK освобождено **22,51 МиБ** при совпадении четырёх контрольных кадров.

## PTC Web

Побайтно точное сжатие полных веб-ресурсов. На выборке из 50 сайтов **125 ресурсов** HTML, CSS и JavaScript заняли **3 283 286 байт** в пакетах при **34 712 469 исходных байтах**. Контрольные записи фиксируют точное восстановление всех 125 ресурсов. Отдельная проверка 20 ресурсов прошла в нативном и браузерном декодерах. В сравнении размера посчитаны пакеты, размер установленного декодера учитывается отдельно.
